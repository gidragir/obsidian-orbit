# ADR 0001: Начальная архитектура проекта obsidian-orbit

- **Статус:** Принято
- **Дата:** 2026-10-09

## Контекст
Инициализация проекта obsidian-orbit (TypeScript / JavaScript (Node/Bun/Deno)) и фиксация базовых архитектурных границ.

## Решение
Внедрение трехуровневой контекстной модели (OpenViking L0/L1/L2) для эффективного взаимодействия с ИИ-ассистентами и разработчиками.

## Последствия
- Вся ментальная карта зафиксирована в L0_index.json.
- Подсистемы документируются независимо в subsystems/.
