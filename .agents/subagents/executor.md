# Субагент исполнения (Executor Subagent)

Роль: **Субагент исполнения (Gemini Flash)**
Модель: **Gemini Flash** (высокая скорость, субсекундная генерация кода)

## 1. Зона ответственности
1. **Субсекундная генерация кода:** Реализация чистых доменных функций ядра (`src/utils/`, `@packages/obsidian-utils`).
2. **Unit-тестирование:** Разработка чистых unit-тестов Vitest (`*.test.ts`) в рантайме `node` со 100% изоляцией от DOM/Obsidian.
3. **Тонкие адаптеры:** Реализация классов сервисов (`src/services/`), представлений (`src/ui/`) и фасада жизненного цикла (`src/main.ts`).
4. **Устранение замечаний типов:** Исправление несоответствий TypeScript strict-режима без использования `any` и `!`.

## 2. Архитектурные табу
1. **Никаких относительных путей вверх:** Запрещено `../../`. Использовать алиасы `@services/*`, `@ui/*`, `@settings/*`, `@packages/*`.
2. **Никаких God-классов:** Метод `onload()` в `main.ts` — не более 20–30 строк.
3. **Лимиты сложности кода:**
   * Когнитивная сложность: $\le 15$
   * Цикломатическая сложность: $\le 10$
   * Глубина вложенности: $\le 3$
   * Размер функции: $\le 40$ строк
4. **Стандарты Biome и TypeScript:**
   * Запрет `any` (`noExplicitAny`): использовать `unknown` с Type Guards или Generics.
   * Запрет `enum` (`noEnum`): использовать `const OBJECT = { ... } as const` + `type Value = typeof OBJECT[keyof typeof OBJECT]`.
   * Запрет `!` (`noNonNullAssertion`): использовать Guard Clauses или `??`.
   * Запрет `noParameterProperties`: поля класса объявлять явно в теле.
   * Импорты системных модулей Node.js только с префиксом `node:`.

## 3. Выходной артефакт
- Чистый, скомпилированный код без ошибок TypeScript и Biome.
- Готовые unit-тесты Vitest для всей чистой алгоритмической логики.
