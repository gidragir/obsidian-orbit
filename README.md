# Obsidian Orbit (`obsidian-orbit`)

Централизованный монорепозиторий (Single Source of Truth, SSOT) для проектирования, разработки, тестирования, сборки и независимого распространения плагинов экосистемы Obsidian.md, а также сопутствующих разделяемых библиотек.

## 🚀 Архитектурные принципы

1. **Единый источник правды (SSOT):** Вся разработка, типизация и версионирование сосредоточены в монорепозитории.
2. **Direct TS Source:** Пакеты `@packages/*` не имеют фазы предварительной сборки и каталогов `dist/`. Бандлер `esbuild` инлайнит TypeScript напрямую в плагины.
3. **Pinpoint-версионирование:** Запрет плавающих версий (`^`, `~`). Все зависимости зафиксированы через `catalog:` в `pnpm-workspace.yaml`.
4. **Порты и Адаптеры (Hexagonal):** Доменное ядро отделено от API Obsidian и DOM на 100%.
5. **Чистые тесты Vitest:** Юнит-тестирование доменной логики в среде `node` без моков классов Obsidian.
6. **Zero-copy контур (`.vault/`):** Плагины подключаются в хранилище через кроссплатформенные симлинки (`pnpm vault:link`).

## 🛠️ Команды тулчейна

```bash
# Установка зависимостей
pnpm install

# Комплексная проверка качества кода (Biome + Typecheck + Test + Build)
pnpm check

# Форматирование и линтинг Biome
pnpm lint && pnpm format

# Проверка типов TypeScript
pnpm typecheck

# Запуск чистых юнит-тестов Vitest
pnpm test

# Сборка всех плагинов через esbuild
pnpm build

# Создание симлинков в тестовое хранилище .vault/
pnpm vault:link

# Режим разработки с watch-сборкой
pnpm dev

# Создание ченджсета изменений
pnpm change

# Бамп версий и синхронизация манифестов
pnpm version:bump

# CLI-мердж релизного PR
pnpm release:merge
```

## 📁 Структура репозитория

```
.
├── .agents/             # ИИ-контекст: правила, навыки, воркфлоу, mcp
├── .agent/workflows/    # Симлинк на .agents/workflows
├── .changeset/          # Каталог изменений Changesets
├── .github/workflows/   # CI/CD пайплайны
├── .vault/              # Локальное хранилище Obsidian (симлинки на плагины)
├── packages/            # Разделяемые библиотеки (@packages/*)
│   ├── tsconfig/        # Базовые конфигурации TypeScript
│   ├── obsidian-utils/  # Доменные утилиты без зависимостей от DOM/Obsidian
│   └── ui/              # Общие UI-компоненты и стили
├── plugins/             # Плагины Obsidian
│   └── example-plugin/  # Пример плагина
└── scripts/             # Служебные скрипты сборки, релизов и линковки
```
